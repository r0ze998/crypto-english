# Crypto English（r0ze 専用 英語練習サイト）

海外の Crypto 開発者と、自分のプロジェクトについて英語で話す練習をするための Web アプリです。単語帳や汎用チャットではなく、**場面ごとの短い会話 → 理解確認 → まねる → 自分の文に置き換える → 追加質問に答える → 詰まった表現を復習**、という流れを毎日回すことを目的にしています。

- 対象: 日本語話者・英語 CEFR A2 程度・オンチェーンゲーム開発者
- スマホ優先（PWA。ホーム画面に追加でき、一度開けばオフラインでも動く）
- サーバーなし。データはすべて端末のブラウザ内に保存
- 有料 API・API キー不要

## 起動方法

```bash
npm install
npm run dev          # http://localhost:5173 （PC で確認）
```

本番ビルドで確認する場合:

```bash
npm run build
npm run preview      # http://localhost:4173
```

### スマホで使う

マイク（録音）は **HTTPS か localhost** でしか使えません。

- 同じ Wi‑Fi のスマホから試す: `npm run dev:lan`（自己署名証明書の HTTPS で起動）。表示される `https://<PCのIP>:5173` をスマホで開き、証明書の警告を許可します。
- 毎日使う: **https://r0ze998.github.io/crypto-english/** をスマホで開いて「ホーム画面に追加」。`main` に push すると GitHub Actions がテスト・ビルドして `gh-pages` ブランチに公開します。

## 練習の流れ

| コース | 内容 |
| --- | --- |
| 10分 | 復習（期日のものを最大3件）＋ 1場面（聞く → 理解チェック → まねる・置き換え → 追加質問1つ → 保存） |
| 30分 | 復習（最大8件）＋ 2場面（追加質問2つずつ）＋ 繰り返し説明（60/45/30秒） |
| 60分 | 復習（最大15件）＋ 3場面 ＋ 繰り返し説明 ＋ ピッチ練習（原文登録時のみ） |

- 英文・日本語訳は既定で非表示（行ごと・全体で表示切替）。キーワードを先に確認してから聞く
- 「分からない…」で、ゆっくり再生・A2 版への切替・英文/訳の表示・聞き返し表現を提示
- 理解度・「分からない」の回数・追加質問の自己評価から、難度（A2 / 少し難しい版 / 速度）の目安を提案（学力判定ではありません）
- ☆ を付けた文や詰まった質問の答え例を保存すると、**翌日以降**の復習に出る（1→2→4→7→15→30→60日の目安）
- 途中で閉じても、同じステップから再開できる

## 教材（14場面・A2 版と少し難しい版）

初対面のあいさつ / 聞き返す / 何を作っているか / 遊び方 / なぜブロックチェーン / 分からないことを認める / Solana / AI エージェント / 共有世界 / 所有権 / 質問を掘り下げる / フィードバックを受けて確認 / ミーティングの約束 / お礼のフォローアップ

- すべてこのアプリ用に書いたオリジナル（`src/data/scenes.ts`）。既存教材の転載はありません。
- 会話の「Sam」は**練習用の架空の開発者**です。Sam のゲームの説明は r0ze さんのプロジェクトの説明ではありません。
- A2 版は1文12語以内（テストで確認）。

## プロジェクト資料とピッチ

- 「資料」タブで 14 項目（一言説明・遊び方・チェーン・ユーザー数・資金調達など）を入力。**「確認済み」にした項目だけ**が練習に表示され、それ以外は「要確認」と表示します。アプリが仕様・実績・資金調達・ユーザー数を作文することはありません。
- **0xARK の固定ピッチは未登録**です。原文が登録されるまで、作文・再構成はしません。
- 登録した原文は入力どおり（空白・改行も含めて）保存し、SHA-256 で改変がないことを確認します。アプリ内に原文の編集機能はありません（削除と新しい版の追加のみ）。インポートでも既存の原文は上書きしません。
- 練習用の言い換えは原文とは別データとして保存・編集します。

## 音声機能と対応状況

| 機能 | 仕組み | データの行き先 |
| --- | --- | --- |
| 読み上げ | Web Speech API `speechSynthesis` | 声の一覧で「端末内」の声は端末内で合成。「ネットワーク」の声は読み上げる英文が提供元のサーバーへ送られる可能性あり。既定は端末内の声を優先し、設定画面で注意を表示 |
| 録音・再生 | `MediaRecorder` + IndexedDB | 端末内のみ。ボタンを押したときだけマイクを開き、停止で閉じる。最長90秒 |
| 音声認識（任意） | `SpeechRecognition` / `webkitSpeechRecognition` | **既定は無効**。有効にすると Chrome は通常 Google のサーバーで認識、Safari は Apple のサーバーで処理される場合あり。文字起こしの参考表示のみで、発音採点には使わない |
| AI 会話（任意） | 自分で指定した OpenAI 互換エンドポイント | **既定は接続なし**。API キー入力欄はない。送るのは入力した答えのテキストと確認済み資料のみ |

発音の点数化はしていません。お手本と自分の録音の聞き比べ（「▶ お手本→自分」）と、チェックリストによる自己確認だけです。

### 検証した環境 / 未検証の環境

| 環境 | 状態 |
| --- | --- |
| Chromium 141（Playwright, Pixel 7 相当の画面） | **検証済み**。この環境は英語の声が0のため、自動でテキスト練習になる経路を実ブラウザで確認。録音は疑似マイクで録音・保存・再生・エクスポートまで確認 |
| 読み上げの動作 | 偽の `speechSynthesis` を差し込んで、全文再生・1行再生・速度・相手/自分の声の切り分けを確認。**実際の声での再生は未検証** |
| iPhone Safari / Android Chrome / PC Safari・Firefox | **未検証**。iOS は 14.3 以降で MediaRecorder（audio/mp4）対応、声は iOS の設定に依存。Firefox は音声認識非対応 |
| 音声認識 | API の有無の検出のみ確認。実際の認識は**未検証** |
| AI 接続 | 疑似サーバーで、キーなしで送信されること・「AI 応答」と表示されることを確認。実際の Ollama 等は**未検証** |

## データの保存・バックアップ

- 練習データ: `localStorage`（キー `crypto-english:v1`）。録音: IndexedDB（`crypto-english-recordings`）
- 設定 → データ: JSON でエクスポート（録音を含めるか選択）、インポート（「今のデータに追加」または「すべて置き換え」）
- iPhone ではしばらく開かないとブラウザのデータが消えることがあるため、定期的なエクスポートを推奨。設定から「永続保存」をリクエストできます。

## テスト

```bash
npm test             # ロジックと教材の整合性（51件）
npm run e2e          # 実ブラウザ（Chromium）での通しテスト（9件）
npm run build:artifact # claude.ai Artifact 用の1ファイル版（録音・音声認識は無効）
```

e2e で確認していること: 10分コースの完走と翌日の復習 / 再読み込み後の再開 / 30分コースの繰り返し説明 / ピッチ原文の保存・整合性・言い換えの分離 / エクスポート→全削除→インポートでの復元（録音を含む）/ 不正ファイルの拒否 / 読み上げ操作（偽の音声合成）/ ネットワーク音声の注意表示・音声認識の既定無効 / AI 接続時の表示と送信内容 / オフライン起動

## 構成

```

  lib/                状態・復習スケジュール・バックアップ・音声・録音・AI 拡張
  components/steps/   練習の各ステップ

tests/                Vitest テスト

```
